# 过早江湖

> 六点四十七分，这条街先于城市醒来。

武汉大学“零杯”网页设计大赛参赛项目。一个以武汉“过早”为文化底色的单页互动叙事体验：用户亲手点燃街边炉火，走进三个早餐摊位，做三次选择，最后带走一张专属“过早卡”。

不是美食攻略，也不是传统展示页。

## 快速开始

要求 Node.js >= 20.19（当前开发环境为 Node 24）。

```bash
npm install
npm run dev
```

开发服务器默认开启局域网访问，可以用同一 Wi-Fi 下的手机打开终端里显示的 Network 地址。

## 技术栈

- Vite 8 + React 19 + TypeScript
- Zustand（场景状态）
- Framer Motion（点火、转场、拖拽）
- Tailwind CSS 4（后续 UI 与卡面）
- Howler.js、html-to-image、Zod（已安装，用于后续音频、卡片导出与内容校验）

```text
docs/

```

## 内容约定

- 文案集中放在 `src/content/stalls.ts`，界面只读取数据，不在组件里硬编码故事。
- 每个摊位恰好两个选项，**两个选项都必须体面**，不设计“正确答案”。
- 人物、摊位为虚构复合创作；使用真实采风素材需征得同意并记录授权。
- 不新增场景、人物或摊位，除非先调整 MVP 范围。
- 首屏原型仅用于验证点火手势与氛围方向，后续界面按策划案继续接入。
